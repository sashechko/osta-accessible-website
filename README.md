# Inovāciju prakses centra “Osta” tīmekļvietne

Šajā repozitorijā atrodas biedrības “Inovāciju prakses centrs “Osta”” tīmekļvietnes pirmkods.

**Tīmekļvietne:** [https://ostacentrs.lv/](https://ostacentrs.lv/)

## Tīmekļvietnes mērķis

- informēt par biedrību, tās darbības virzieniem un pakalpojumiem;
- publicēt biedrības un projektu aktualitātes;
- sniegt informāciju par projektu “Atlabšanas ceļvedis” pilnajā un viegli lasāmajā versijā;
- nodrošināt saprotamu un pēc iespējas piekļūstamu saziņu ar biedrību.

## Uzturēšana

Tīmekļvietne ir statiska HTML un CSS vietne, kas publicēta ar GitHub Pages un piesaistīta domēnam `ostacentrs.lv`.

Pirms izmaiņu publicēšanas jāpārbauda:

- lapu darbība mobilajā un darbvirsmas skatā;
- navigācija ar tastatūru un redzams fokuss;
- virsrakstu struktūra, saišu nosaukumi un attēlu tekstuālās alternatīvas;
- lokālās saites un HTML derīgums;
- projekta publicitātes prasības;
- piekļūstamības paziņojuma aktualitāte.

Par tīmekļvietnes saturu un uzturēšanu atbild biedrība “Inovāciju prakses centrs “Osta””.
